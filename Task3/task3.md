# Оценка Data Encryption at Rest and In Transit

## Стратегия защиты данных в системе

### Классификация данных по состоянию, чувствительности и риску

| Категория данных                                                          | Состояние данных    | Уровень чувствительности | Профиль риска                                                           | Необходимость защиты                                                                   | Примеры угроз                                              |
| ------------------------------------------------------------------------- | ------------------- | ------------------------ | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Персональные данные пациентов (ФИО, дата рождения, телефон, email, адрес) | Хранение / Передача | Высокая                  | Утечка персональных данных, штрафы по GDPR/152-ФЗ, репутационные потери | Требуется защита по закону, необходимость предотвращения утечек                        | Перехват при передаче, доступ без авторизации              |
| Медицинские данные (история болезни, диагнозы, анализы, снимки)           | Хранение / Передача | Очень высокая            | Неправомерный доступ, дискриминация, утрата доверия                     | Защита регламентируется HIPAA, ISO 27799, клиническими стандартами                     | Утечка данных из БД, несогласованный обмен между сервисами |
| Финансовые данные (платежи, банковские счета, реквизиты)                  | Хранение / Передача | Высокая                  | Финансовые потери, мошенничество, компрометация счётов                  | Защита необходима для соблюдения PCI DSS, предотвращения несанкционированных переводов | Кража данных, атаки на шлюзы оплаты                        |
| Служебные учётные записи, токены, ключи API                               | Хранение            | Критическая              | Полный компромисс системы при утечке                                    | Обязательное шифрование, контроль доступа, регулярная ротация                          | Утечка .env, hardcoded секреты, утечка в логах             |
| Метаданные (временные метки, источник, история изменений)                 | Передача            | Средняя                  | Недостоверный аудит, проблемы с трассировкой                            | Обеспечение целостности, особенно в системах аудита, аналитики                         | Манипуляции при передаче, подмена данных                   |
| Агрегированные BI/отчёты без персональных данных                          | Хранение / Передача | Низкая                   | Потеря конкурентного преимущества                                       | Защита рекомендована в B2B-контексте или при наличии интеллектуальной собственности    | Кража бизнес-инсайтов                                      |

### Инструменты защиты данных

| Тип данных                                             | Инструменты защиты                                                                                                                                                                                                                    |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Данные в состоянии хранения (Data at Rest)**         | - AES-256 шифрование БД (PostgreSQL TDE, MongoDB Encrypted Storage)<br> - Использование HSM (Hardware Security Module) для хранения ключей<br> - ФС с поддержкой LUKS/eCryptFS<br> - Hashing чувствительных полей (например, паролей) |
| **Данные при передаче (Data in Transit)**              | - TLS 1.2+ (HTTPS, mTLS между микросервисами)<br> - VPN/IPSec для подключения внешних систем<br> - Защищённые API шлюзы (например, Kong, WAF)<br> - Использование безопасных транспортов (Kafka with SSL, gRPC over TLS)              |
| **Управление доступом**                                | - RBAC/ABAC<br> - Многофакторная аутентификация (MFA)<br> - Журналирование доступа (audit logs)<br> - Поддержка OPA (Open Policy Agent)                                                                                               |
| **Защита данных в логах и дампах**                     | - Автоматическое маскирование PII/PHI<br> - Использование логгеров с фильтрами (например, Serilog Filters)<br> - Удаление дампов и логов старше X дней                                                                                |
| **Обезличивание и псевдонимизация**                    | - Псевдонимы, токенизация (например, Hashids)<br> - Использование UUID вместо ФИО<br> - Форматирование на уровне БД или в ETL-пайплайне                                                                                               |
| **Обнаружение и защита в реальном времени (RASP/DLP)** | - Обнаружение утечек с помощью DLP-систем (например, Symantec, Microsoft Purview)<br> - RASP-инструменты в приложении (например, Sqreen, Contrast Security)                                                                           |

### Автоматизированный контроль и аудит

| Направление контроля            | Инструмент / Метод                                              |
| ------------------------------- | --------------------------------------------------------------- |
| Мониторинг шифрования БД и TLS  | Security Benchmark (например, CIS PostgreSQL, TLS Scanner)      |
| Контроль доступа и активности   | Audit Trail + SIEM (ELK, Graylog, Splunk)                       |
| Анализ уязвимостей              | SAST/DAST (SonarQube, Checkmarx, OWASP ZAP)                     |
| Обнаружение утечек / нарушений  | DLP-системы (Microsoft Purview, Zecurion DLP, Safetica)         |
| Интеграция политик безопасности | Open Policy Agent, Kyverno (для Kubernetes), HashiCorp Sentinel |
| Контроль за конфигурацией       | Infrastructure as Code Scanning (Checkov, tfsec, OPA Rego)      |

### Реестр программных и аппаратных средств защиты

| Название                    | Тип                               | Назначение                                   |
| --------------------------- | --------------------------------- | -------------------------------------------- |
| HashiCorp Vault             | ПО                                | Хранение и ротация секретов                  |
| PostgreSQL TDE              | ПО                                | Transparent Data Encryption на уровне СУБД   |
| TLS 1.3 + mTLS              | Протокол                          | Шифрование данных при передаче               |
| Open Policy Agent (OPA)     | ПО                                | Контроль доступа по политикам                |
| HSM (YubiHSM, AWS CloudHSM) | Аппаратное / облачное             | Аппаратное хранилище ключей                  |
| Microsoft Purview           | DLP + классификация               | Классификация и защита чувствительных данных |
| Serilog + Masking           | Логирование                       | Автоматическое маскирование PII/PHI в логах  |
| SonarQube + OWASP ZAP       | Статический / динамический анализ | Безопасность кода                            |
| Kafka with SSL/TLS          | Шина данных                       | Шифрование и защита Kafka-сообщений          |
| LUKS / eCryptFS             | Шифрование томов                  | Шифрование жёстких дисков                    |
| Azure Key Vault / AWS KMS   | Облачные менеджеры                | Управление ключами                           |
